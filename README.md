# Indica Independent Media — hub

**Open intelligence, built in the open.** This is the index for the IIM estate: the agent
architecture, the AT Protocol work, the OSINT worker patterns, the research studies and the
media kits. Every repository listed here is public and stands on its own.

> **What Wall Street hoards, we hand back.**

The mission tooling — free software for defending people who cannot buy the software that would
help them — is indexed separately at
**[vpdlny-tools](https://github.com/indicaindependent/vpdlny-tools)**. This hub is the media and
intelligence side of the house.
